# Безопасность GAMEQIVA

## Сообщение об уязвимости

Не публикуйте действующие токены, персональные данные и инструкции по эксплуатации уязвимостей в открытых Issues.

Для приватного сообщения используйте [GitHub Security Advisories](https://github.com/Zeihos/Gameqiva/security/advisories), если в репозитории включена возможность частного сообщения об уязвимостях. Если она недоступна, свяжитесь с владельцем репозитория через его публично указанные каналы связи, **не раскрывая секреты публично**.

## Хранение секретов

- API-ключи должны находиться в **GitHub Actions Secrets** или локальном `.env`, который исключён из Git.
- Не записывайте значения токенов в логи.
- При подозрении на утечку немедленно отзовите токен у провайдера и создайте новый.
- Для VK различайте токен сообщества и пользовательский токен загрузки фотографий.

## Область проекта

Особое внимание уделяется публикации от имени сообщества, работе с внешними RSS и сохранению состояния, чтобы не создавать повторные посты.
