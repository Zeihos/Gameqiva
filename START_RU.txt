GAMEQIVA | АВТОПОСТИНГ В VK + TELEGRAM
====================================

Это отдельная система автопубликации (а не ChatGPT «Задачи»).
Каждые 3 часа она ищет свежую статью на официальных PlayStation Blog / Xbox Wire,
проверяет дату, выбирает значимую новость, пишет короткий русский пост,
берёт официальное изображение со страницы новости и публикует
один и тот же пост в VK и Telegram. Повторы отсеиваются.
Если за сутки нет подходящего инфоповода, публикация пропускается.

ПЕРВОНАЧАЛЬНАЯ НАСТРОЙКА (БЕЗ ПЕРЕДАЧИ КЛЮЧЕЙ В CHATGPT)
1. Создай ПРИВАТНЫЙ репозиторий GitHub, загрузи в корень содержимое этого архива.
   ВАЖНО: папка .github скрытая, она должна попасть в репозиторий.
2. В Settings > Secrets and variables > Actions добавь секреты:
   OPENAI_API_KEY = ключ OpenAI API (дополнительная платная API-услуга, не ChatGPT Plus)
   VK_USER_TOKEN = токен пользователя-администратора VK с правами wall и photos
   VK_GROUP_ID = числовой положительный ID сообщества (не ссылка/псевдоним)
   TG_BOT_TOKEN = токен Telegram-бота от @BotFather
   TG_CHAT_ID = @публичный_канал или числовой ID Telegram-канала
3. В Telegram добавь созданного бота администратором канала с правом публикации.
4. В VK включи доступ к API для пользователя-администратора сообщества.
   Внимание: токен СООБЩЕСТВА может не поддерживать загрузку фото на стену;
   здесь нужен пользовательский токен с нужными правами.
5. В GitHub открой вкладку Actions > GAMEQIVA Auto Publish > Run workflow.
   Проверь журнал первого запуска и наличие фотографий на обеих площадках.
6. Дальше публикации будут запускаться GitHub Actions автоматически
   в 08/11/14/17/20/23/02/05 по времени Europe/Amsterdam (включая переходы DST).

ОГРАНИЧЕНИЯ
- Репозиторий должен иметь включённые GitHub Actions; запуски GitHub иногда задерживаются.
- Приложение не берёт текст из чата ChatGPT: оно самостоятельно выбирает новости
  через RSS и использует OpenAI API для написания поста.
- Источники сейчас: PlayStation Blog, Xbox Wire. Другие площадки можно добавить
  только после проверки актуальных официальных RSS.
- Публикуется одна новость за один проход, только если найдена подходящая
  официальная иллюстрация. Снимки НЕ создаются искусственным интеллектом.
- Текст генерируется по данным первоисточника: автоматическую проверку каждого
  утверждения человеком это НЕ заменяет. Начни с тестового канала/сообщества.
- При сбое одной площадки система при следующем запуске попробует допубликовать
  тот же материал на неё, не дублируя успешную публикацию.
- Если GitHub не позволяет записать state.json, отключи публикации до исправления:
  без сохранения состояния возможны дубли.
- Если исходная статья или изображение недоступны, пост не публикуется.

ЛОКАЛЬНЫЙ ТЕСТ (Windows)
  py -m venv .venv
  .venv\Scripts\activate
  pip install -r requirements.txt
  copy .env.example .env
  Заполни .env только у себя. Для просмотра без публикации оставь DRY_RUN=1.
  python run.py
  Для реальной публикации: DRY_RUN=0.

Не выкладывай .env, токены и API-ключи в соцсети или в чат.
