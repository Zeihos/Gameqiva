GAMEQIVA | АВТОПУБЛИКАЦИЯ В VK + TELEGRAM
=======================================

Подготовлено под:
 VK: https://vk.ru/gameqiva
 Telegram: https://t.me/gameqivo
 GitHub: https://github.com/Zeihos/Gameqiva

СТАТУС: КОД ПОДГОТОВЛЕН. ПУБЛИКАЦИЯ НЕ ЗАПУЩЕНА, ПОКА НЕ ДОБАВЛЕНЫ СЕКРЕТЫ
И НЕ ПРОВЕРЕН ПЕРВЫЙ ЗАПУСК. Обычная ChatGPT-задача посты не публикует.

РАЗОВАЯ НАСТРОЙКА
1) Открой GitHub Zeihos/Gameqiva. Желательно приватный репозиторий.
   Залей В КОРЕНЬ все файлы из папки gameqiva_autopost, включая скрытую
   .github/workflows/autopost.yml, run.py, requirements.txt и data/state.json.
   Папку gameqiva_autopost создавать на GitHub НЕ нужно.
2) GitHub -> Settings -> Secrets and variables -> Actions -> New repository secret:
     OPENAI_API_KEY   = рабочий ключ OpenAI API (не подписка ChatGPT Plus)
     VK_USER_TOKEN    = токен администратора ВК с разрешениями wall и photos
     TG_BOT_TOKEN     = токен бота, созданного через Telegram @BotFather
   В файлах исходного кода и в GitHub Issues эти токены НЕ размещай.
3) В Telegram-канале @gameqivo назначь бота администратором,
   включи право "Публикация сообщений".
4) В VK администратор сообщества gameqiva должен иметь право публикации.
   Бот через VK API разрешит короткий адрес gameqiva в числовой ID.
   Если API не позволяет разрешить адрес, добавь в GitHub -> Actions Variables
   необязательную переменную VK_GROUP_ID (положительный числовой ID группы).
5) В GitHub -> Actions -> GAMEQIVA Auto Publish -> Run workflow:
   первый раз оставь publish = false, чтобы увидеть превью, без постинга.
   Затем вручную publish = true для проверки фактической публикации.
6) После успешного теста планировщик GitHub Actions автоматически запустит
   публикации в 08:00 / 11:00 / 14:00 / 17:00 / 20:00 / 23:00 / 02:00 / 05:00
   по часовому поясу Europe/Amsterdam (с учетом летнего времени).
   События cron у GitHub могут задерживаться, не гарантия секунду в секунду.

КАК ЭТО РАБОТАЕТ
- Берет материалы из официальных RSS PlayStation Blog и Xbox Wire.
- Выбирает одну новую значимую новость за последние 24 часа.
- Использует OpenAI API для написания русского поста в стиле GAMEQIVA.
- Прикрепляет РЕАЛЬНУЮ иллюстрацию официального материала.
- Автоматически публикует один и тот же пост в VK и в Telegram.
- Сохраняет историю публикаций для уменьшения повторов.
- Если проверенной новости или фотографии нет, выпуск пропускается.

ВАЖНО
- Приложение автономно и НЕ берет тексты из переписки ChatGPT.
- Успешная проверка текста моделью не гарантирует отсутствие фактических ошибок.
- Два источника не покрывают всю индустрию; пока публикации могут быть реже.
- Для OpenAI API нужна отдельная оплата; вызовы не входят в ChatGPT Plus.
- Полностью без вмешательства это работает только при активных API-ключах,
  разрешениях и исправном GitHub Actions.
- Если публикация произошла, но GitHub не смог сохранить data/state.json,
  временно отключи Action до устранения причины: иначе возможны дубли.
- ВК разрешения и токены могут меняться. Если API отвергает публикацию,
  смотри ошибки в Actions; никаких автоматических обходов безопасности нет.

ЛОКАЛЬНЫЙ ТЕСТ (WINDOWS)
  py -m venv .venv
  .venv\Scripts\activate
  pip install -r requirements.txt
  copy .env.example .env
  Заполни .env на своём компьютере и оставь DRY_RUN=1.
  python run.py

Никому не отправляй токены и API-ключи. Конфиденциальные данные —
только в GitHub Actions Secrets или в локальном .env (в .gitignore).
