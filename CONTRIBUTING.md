# Участие в разработке GAMEQIVA

Спасибо за интерес к проекту!

## Как предложить улучшение

1. Проверьте, нет ли уже похожей задачи в [Issues](https://github.com/Zeihos/Gameqiva/issues).
2. Опишите проблему, ожидаемое поведение и способ воспроизведения.
3. Для изменений кода создайте отдельную ветку и Pull Request.
4. Приложите результаты тестов и объясните, что изменилось.

## Проверка перед Pull Request

```bash
python -m pip install -r requirements.txt
python -m unittest -q test_editorial test_editorial_safety test_rss_collector test_feed_health test_vk_publishing
```

Старайтесь сохранять простой код, понятные сообщения об ошибках и защиту от повторных публикаций.

**Не добавляйте в Pull Request** реальные API-токены, содержимое `.env`, личные данные, дампы запросов с секретами или чужие материалы без разрешения.

Основной язык документации и обсуждений — **русский**. Английский также допустим.
